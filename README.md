# GitHub Pages Personal Site Starter

This is a lightweight personal homepage inspired by clean one-page academic sites like SinglePaged and mattocci27.github.io.

## Preview

Open `index.html` in a browser.

## Publish On GitHub Pages

1. Create a GitHub repository named `nt-duyen.github.io`.
2. Copy these files into that repository:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/research-landscape.png`
   - `assets/cv.pdf`
3. Commit and push to the `main` branch.
4. In GitHub, open the repository settings and make sure Pages is publishing from the `main` branch.

Your site will appear at:

```text
https://nt-duyen.github.io
```

## Edit Your Content

Most of the content is in `index.html`.

Change these first:

- news items
- research links
- publication titles
- email, GitHub, Google Scholar, and CV links

## Replace The Image

The image at `assets/research-landscape.png` is used as a small news thumbnail. You can replace it with a field photo, lab photo, paper figure, or research image. Keep the same filename if you do not want to edit the HTML.

## Replace The CV

The CV link points to:

```text
assets/cv.pdf
```

Replace that file with a newer CV whenever you want to update it.
